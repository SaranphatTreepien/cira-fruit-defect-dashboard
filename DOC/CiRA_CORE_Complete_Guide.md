# 2. ที่มาของโปรแกรม CiRA Core ✅ PDF

CiRA CORE เป็นแพลตฟอร์มปัญญาประดิษฐ์ (AI) ที่เกิดจากความร่วมมือระหว่าง

- สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง
- มหาวิทยาลัยขอนแก่น
- มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ

โดยร่วมมือกันนับตั้งแต่ปี พ.ศ. 2553 เป็นต้นมา เมื่อ Deep Learning ได้รับความนิยมอย่างมากในสาขา AI และมีความต้องการใช้ในการพัฒนาเพิ่มมากขึ้น จึงมีการขอทุนวิจัยจากภาครัฐบาลเพื่อพัฒนาแพลตฟอร์มของคนไทยเอง จึงเป็นที่มาของทั้ง 3 มหาวิทยาลัยที่ร่วมมือกันพัฒนา CiRA CORE ขึ้นมา

เวอร์ชันแรกเป็นรุ่น Python ซึ่งเป็นการเขียนโปรแกรมภาษา Python ลงไป ให้บริษัทขนาดใหญ่ใช้งานได้ แต่ไม่สามารถนำไปให้กับ SMEs ได้ เนื่องจากไม่มีโปรแกรมเมอร์ที่ (ข้อความในใบความรู้ถูกตัดที่ขอบหน้า ส่วนท้ายประโยคไม่ปรากฏครบ)

**ข้อมูลเสริม** ✅ เอกสารอื่น (บทความ IEEE 2024): CiRA CORE เป็นศูนย์กลางเชื่อมการสร้างเทคโนโลยี AI เข้ากับการใช้งานจริง ทำงานร่วมกับ ROS (Robot Operating System) และเชื่อมระบบต่าง ๆ ผ่านอินเทอร์เฟซแบบลากวาง ลดการเขียนโค้ด เหมาะกับผู้มีพื้นฐานการเขียนโปรแกรมน้อย ครอบคลุมการสร้างอัลกอริทึม เทรนโมเดล AI การเชื่อมต่ออุปกรณ์ในโรงงาน งานรู้จำภาพ การจัดเก็บข้อมูลและ label เป้าหมายคือทำให้ AI และหุ่นยนต์เข้าถึงง่ายสำหรับ Industry 4.0

## 5.2 วิธีใช้งานพื้นฐาน ✅ PDF (จากภาพ node)

- ลาก node จาก toolbox มาวางใน canvas แล้วเชื่อมสายระหว่างจุดสีน้ำเงินด้านซ้าย (input) และด้านขวา (output)
- node ส่วนใหญ่มีสวิตช์เปิด/ปิด (toggle), ไอคอนเฟือง (ตั้งค่า) และป้ายสถานะสีเหลือง/แดง
- Get/Set ส่งข้อมูลแบบ "ไร้สาย" (ไม่ต้องลากสาย) โดยจับคู่กัน

# 7. ตัวอย่าง flow ที่พบบ่อย (ประกอบจากหน้าที่ของ node)

1. **ตรวจจับวัตถุจากกล้อง**: `AutoRun` → `WebCam` → `DeepDetect` → `Image` (แสดงผล)
2. **ตรวจจับแล้วสั่งอุปกรณ์**: `WebCam` → `DeepDetect` → `IfElse` → `WriteOutput`
3. **แจ้งเตือนเมื่อพบความผิดปกติ**: `DeepDetect` → `IfElse` → `LineBot` / `TGNotify`
4. **ส่งข้อมูลเข้าระบบอื่น**: `DeepDetect` → `MqttPub` หรือ `RestPutJson`
5. **หุ่นยนต์หยิบชิ้นงาน**: กล้อง → `DeepDetect` / `PatMatch` → `Move` / `MoveSeq`
6. **เก็บภาพไว้เทรนโมเดล**: `WebCam` → `ImageCapture` (กด Capture เก็บเป็นไฟล์) แล้วนำไปใช้กับ `DeepTrain` / `ClassifTrain`
7. **ส่งข้อมูลข้าม flow โดยไม่ลากสาย**: `FlowDataSet` (Set) ในฉากหนึ่ง → `FlowDataGet` (Get) ในอีกฉากหนึ่ง

> ตัวอย่างข้างต้นเป็นการประกอบให้เห็นภาพ ไม่ใช่ตัวอย่างทางการจากใบความรู้

1. **เลขเวอร์ชันไม่ตรงกัน**: ข้อความใน PDF เขียน `CiRA-CORE_1.1 beta-03` แต่ชื่อไฟล์/หน้าจอติดตั้งในภาพแสดง `beta-08` (vulkan) และมุมขวาบนของโปรแกรมแสดงทั้ง beta-03 และ beta-08 ในภาพต่างหน้า จึงควรดูเวอร์ชันจากไฟล์ที่ดาวน์โหลดจริง
